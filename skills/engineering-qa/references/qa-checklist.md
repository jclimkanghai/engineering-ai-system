# Final QA Checklist

- [ ] Source identified
- [ ] Document registry checked where available
- [ ] Revision and governing status considered
- [ ] Supersession and addenda considered
- [ ] Source location verified
- [ ] Evidence metadata includes document ID, revision, page/section/locator, and discipline where available
- [ ] Requirement and responsibility identified
- [ ] Evidence linked
- [ ] Fact, interpretation, judgement, and assumption separated
- [ ] Unknowns explicit
- [ ] Strongest reasonable interpretation tested
- [ ] Contradictory evidence checked
- [ ] Risk and confidence separated
- [ ] No invented citations or values
- [ ] Finding registry reconciliation checked before approved persistence
- [ ] Human review gate applied
