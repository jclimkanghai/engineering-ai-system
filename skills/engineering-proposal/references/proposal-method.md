# Proposal Method

Use existing project prompts as the detailed source methodology. Proposal outputs must be traceable to tender/RFQ/RFP source material and distinguish contractual requirements, technical expectations, industry practice, assumptions, exclusions, interfaces, and unknowns. Assess technical, commercial, programme, contractual, resource, and interface exposure separately.

For project-backed work, establish the governing document set through the document registry and use retrieval evidence before making a proposal claim. Record clarification items when the source does not prove scope, responsibility, deliverables, standards, acceptance criteria, access constraints, programme constraints, or interfaces.
