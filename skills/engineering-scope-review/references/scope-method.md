# Scope Method

Primary source: `prompts/scope.md`. Cross-check with `prompts/contractual.md` and `prompts/master_reviewer.md`. Scope decisions require evidence. An item is not automatically out of scope because it is omitted from one document, and it is not automatically in scope because it is common practice.

For project-backed reviews, resolve the document set through the document registry where available. Check revision, governing status, supersession, referenced documents, exclusions, interfaces, addenda, clarifications, and later revisions before classifying scope.
