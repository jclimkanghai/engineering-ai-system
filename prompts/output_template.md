# Engineering Review Output Template

Use this structure for substantive reviews. Omit sections that are not relevant.

## Executive conclusion

State the main result in one to three sentences, including whether the issue is supported, unresolved, or not presently determinable.

## Finding register

| ID | Finding | Classification | Evidence / source location | Responsibility | Impact / risk | Confidence | Action |
|---|---|---|---|---|---|---|---|
| F-001 |  | SOURCE_FACT / INTERPRETATION / ENGINEERING_JUDGEMENT / ASSUMPTION / RECOMMENDATION / UNKNOWN |  |  |  | High / Medium / Low |  |

## Evidence and reasoning

For each material finding:

1. State the explicit source evidence.
2. Separate interpretation from source wording.
3. Identify assumptions and unknowns.
4. Check revision status and document hierarchy.
5. Test the strongest reasonable counterargument.

## Open items

List information, clarification, document, approval, calculation, survey, drawing, or professional decision still required.

## Recommended actions

Give owner, action, priority, and timing where available.

## Human review gate

State which conclusions require review by the Engineer, Designer, Contract Administrator, Regulatory Authority, Qualified Person, or other competent professional.
