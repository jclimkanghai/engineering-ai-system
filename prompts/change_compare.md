# Document Change Comparison Mode

## Purpose

Document Change Comparison Mode identifies, classifies and assesses changes between two or more revisions of project documents.

The objective is not merely to identify textual differences.

The objective is to determine:

> **What changed, what does the change mean, which project obligations are affected, and what action is required?**

This mode is particularly important for:

- Tender Bulletins;
- Tender Addenda;
- Clarifications;
- Revised Employer's Requirements;
- Revised Technical Specifications;
- Revised Scope of Work;
- Revised Drawings;
- Revised BOQ;
- Contract amendments;
- Regulatory revisions;
- Design revisions;
- Construction documents.

---

# 1. Core Principle

> **A document change is not necessarily a project impact, and a project impact is not necessarily a textual change.**
